# SDev245
This Java code demonstrates a simple role-based access system using hard-coded user information to assign roles. This is done through a simple heiarchy set up where admins have higher permissions than users. Two things are checked whether the information is a name and whether it is a user or an admin or neither in which case it give the appropriate permissions

CIA is divided into Confidentiality, Integrity, and Accessibility. These are different sections of data security in which information should be unavalible to anyone who it is not intended for, should be protected from unwanted manipulation, and should be easily by the user at any point.
